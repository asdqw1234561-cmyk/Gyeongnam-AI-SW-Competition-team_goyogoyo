## 관찰된 한계 (사실 그대로)

- **같은 유형끼리만 비교한다**: 창원시 구와 김해시처럼 유형이 다른 지역은 한 표에서 점수로 비교하지 않는다. 22개를 한 번에 비교하면 시설 수 그대로는 큰 시가, 인구 1만 명당은 넓은 군이 늘 상위가 되는 왜곡을 확인했기 때문이다(DEC-21).
- **인구당 버스정류장 수는 교통 편의가 아니다**: 군 지역(의령군 1만 명당 267.6개)처럼 넓게 흩어진 곳에서 크게 나온다. 실제 이동시간 데이터가 없어 보정하지 못한다.
- **역할이 같은 지역에 겹칠 수 있다**: TC1(최적·균형 마산합포구), TC5(최적·균형 통영시). 역할마다 정해진 기준(종합 1위 / 가장 약한 축이 가장 높은 지역 / 최적 후보의 약한 축에서 앞서는 지배되지 않은 지역)을 계산한 결과 같은 지역이 뽑힌 것이며, 화면에서는 한 줄로 합쳐 보여준다. TC2의 대안(거제시)은 종합 6위지만 규칙상 최적 후보의 약점(생활편의)을 보완하는 지역이다.
- **AI 다듬기는 품질이 일정하지 않다**: 이번 5건 중 2건(TC2·TC4)은 검증 통과, 3건(TC1·TC3·TC5)은 강점·약점을 바꿔 써서 거부됐다. 거부돼도 화면에는 사실인 기본 설명이 나온다(OPEN-7).
- **가성비 후보는 어떤 시나리오에서도 나오지 않는다**: 주거비 데이터가 미확보(G4, 전월세 API 승인 반영 대기)라서다.
- 이 문서의 AI 칸은 1회 실행 관찰값이다. AI 응답은 실행마다 달라질 수 있고, 결정적 칸(가중치·점수·역할·Critic·기본 설명)은 같은 데이터에서 항상 같다.
- 화면의 버튼 클릭 흐름(승인·거절)은 AppTest로 일부 확인했고, 실제 브라우저 확인은 별도로 필요하다.
