# 브라우저 E2E 수동 확인 체크리스트 (제출 전)

> 기준 코드: `jhy-next` `cabc379` (경상남도 22개 지역 버전, 기능 동결). 작성 2026-10-04.
> 자동 테스트(단위 506개, AppTest)는 통과했지만 **실제 브라우저 클릭 흐름은 아직 아무도 확인하지 않았다.**
> 아래 기대값은 현재 데이터로 Python이 계산한 결정적 값이다(같은 입력이면 항상 같다). AI 문장·AI 추가질문은 실행마다 달라질 수 있다.
> 실패하면 "결과" 칸에 증상·화면 위치를 적고, 브라우저 E2E를 막는 명확한 버그만 최소 수정한다(새 기능 금지).

## 0. 준비

| 확인 | 내용 |
|---|---|
| ☐ | `.env`에 `LLM_BACKEND=ollama`(기본). Ollama 실행 중, `ollama list`에 `qwen3.5:4b` |
| ☐ | `streamlit run app.py` → 브라우저에서 첫 화면 제목 "🏡 경남 이주자 맞춤형 생활권 탐색 AI" |
| ☐ | 사이드바에 `app`, `user`(관심 위치 탐색), `government`(정부용) 페이지가 보임 |
| ☐ | 시연 녹화를 겸한다면 화면 배율·창 크기 고정 |

**Ollama가 꺼져 있어도** 추천 자체는 진행된다(AI 계획 실패 → 기본 절차, 설명은 Python 기본 설명). 이 경우 "Agent가 실제로 한 일"에 "기본 분석 절차로 진행" 경고가 나오는 것이 정상이다.

공통 기대(모든 결과 화면):
- 점수 축은 교통·의료·생활편의 3개, **인구 1만 명당** 비교 문구가 보임
- 가성비 후보는 "💰 가성비 — 제공 안 함: 주거비(월세·전세) 데이터가 미확보…"
- AI 설명 아래에 "✅ … 검증을 통과했습니다" 또는 "📋 계산으로 확정된 사실…만으로 작성한 설명" 중 하나
- 화면 어디에도 예외(빨간 traceback)가 없음

| 5-4 | "📋 데이터 출처와 한계" | 사용한 공공데이터 표(버스·의료·편의점·주민등록 인구 출처·기준일), 아직 없는 데이터, 반영 못 한 입력 | ☐ |
