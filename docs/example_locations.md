# 위치 탐색 예시 위치 (경남 22개 지역 대표 근사 좌표)

`pages/user.py`의 "예시 위치 선택"은 **예시 위치 범위(구 5곳 / 시 7곳 / 군 10곳) → 세부 지역** 2단계로 고른다.
목록과 좌표는 `services/example_locations.py` 한 곳에만 있다.

- 좌표는 **검색 시작을 위한 시·군·구청 부근 대표 근사 좌표**다. 정확한 건물 출입구 좌표가 아니며 특정 주거지 추천이 아니다.
- 반경 계산(하버사인 직선거리 300m/500m/1km)·시설 조회·지역 판정·위치 Agent는 바꾸지 않았다. 예시 위치는 `search_center`의 시작값만 정한다.
